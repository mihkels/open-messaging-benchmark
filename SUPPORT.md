# Getting help

Start with the [documentation site](https://mihkels.github.io/open-messaging-benchmark/). If it
doesn't answer your question, use the channel that fits:

|                You have                 |                                                 Go to                                                 |
|-----------------------------------------|-------------------------------------------------------------------------------------------------------|
| A question, or need help running a test | [Discussions Q&A](https://github.com/mihkels/open-messaging-benchmark/discussions/categories/q-a)     |
| A feature idea or a new driver request  | [Discussions Ideas](https://github.com/mihkels/open-messaging-benchmark/discussions/categories/ideas) |
| A bug or a documentation problem        | [New issue](https://github.com/mihkels/open-messaging-benchmark/issues/new/choose)                    |
| A security vulnerability                | Private report, as described in [`SECURITY.md`](SECURITY.md)                                          |

Issues are only for bug reports and documentation problems. Questions and feature requests opened
as issues are moved to Discussions or closed.

This project is maintained by volunteers. There is no guaranteed response time.

Everyone taking part in issues, pull requests and discussions follows the
[code of conduct](CODE_OF_CONDUCT.md).
