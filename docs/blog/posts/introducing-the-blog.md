# Introducing the OMB blog

The OpenMessaging Benchmark site now has a blog. Posts here cover what changes in the maintained
fork: releases, new and updated drivers, methodology notes and changes to how benchmarks run.

<!-- more -->

## What changed on the site

- The documentation now lives under the **Docs** tab. Every page keeps its existing URL.
- The site is built with [Zensical](https://zensical.org/), the successor to Material for MkDocs.
- Posts are published as an [RSS feed](../../feed_rss_created.xml) and a
  [JSON feed](../../feed_json_created.json).

## What the blog will not do

The project still does not publish benchmark results or comparisons between messaging systems. Run
the benchmark on hardware and configurations that match your own use case; the
[Fair comparisons](../../methodology/fair-comparisons.md) page explains how to set that up.
